Infinite Campus API Self Hosting Guide

This Page Is A Tutorial Of How To Host The Infinite Campus API Via Cloudflare Worker

How To Self Host The Infinite Campus API:

The Infinite Campus API Is Very Complex So Truly Self Hosting
Is Very Hard To Do.
This Article Will Teach You How To Self Host The Infinite Campus API

The Requirements For This Are As Follows:
A Cloudflare Account


Step 1:

Navigate To Cloudflare Workers On You Cloudflare Dashboard

Step 2:

Create A New Cloudflare Worker With The Hello World Template

Step 3:

Click The Edit Code Button In The Top Right Corner And Paste In The Following Code 
                    
  export default {
    async fetch(req) {
      const url = new URL(req.url);
      url.protocol = "https:";
      url.hostname = "api.infinitecampus.xyz";
      url.hash = "";
      const headers = new Headers(req.headers);
      headers.set("Host", url.hostname);
      const newRequest = new Request(url.toString(), {
        method: req.method,
        headers,
        body: req.method === "GET" || req.method === "HEAD" ? null : req.body,
        redirect: "follow",
      });
      const res = await fetch(newRequest);
      return res;
    },
  };


Step 4:

Click The Blue Deploy Button In The Upper Right Corner

Step 5:

Go To The Settings On Infinite Campus And Set The Backend URL To The URL That Is In The Address Bar Below The Deploy Button
