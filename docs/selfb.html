Infinite Campus BYOD Hosting Guide

This Page Is A Tutorial Of How To Host Infinite Campus Via BYOD

How To Self Host Infinite Campus:

Infinite Campus Now Has A BYOD (Bring Your Own Domain) IP Address
This Allows You To Use Your Own Domain To Host Infinite Campus.

Step 1: In Your Domain Registar/Host Service, Find The DNS Records

Step 2: Create A New DNS Record With These Settings:
Type: A
Name: Whatever You Want
Points To: 131.186.2.46
TTL: Auto (Or Don't Change)
If You Have The Option To Proxy It, Do Not Proxy It
