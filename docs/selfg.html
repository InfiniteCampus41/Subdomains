Infinite Campus Self Hosting Guide

This Page Is A Tutorial Of How To Host The Infinite Campus Via Github Pages

How To Self Host Infinite Campus:

The Requirements For This Are As Follows:
A Cloudflare Account
A Github Account


Step 1:

Navigate To Cloudflare Workers On You Cloudflare Dashboard

Step 2:

Create A New Cloudflare Worker With The Hello World Template

Step 3:

Click The Edit Code Button In The Top Right Corner And Paste In The Following Code 
                    
    export default {
        async fetch(request) {
            const url = new URL(request.url);
            const target =
                "https://www.infinitecampus.xyz" +
                url.pathname +
                url.search;
            const response = await fetch(target, {
                headers: {
                    "User-Agent": "Mozilla/5.0"
                }
            });
            const headers = new Headers(response.headers);
            headers.set("Access-Control-Allow-Origin", "*");
            headers.set("Access-Control-Allow-Methods", "*");
            headers.set("Access-Control-Allow-Headers", "*");
            return new Response(response.body, {
                status: response.status,
                statusText: response.statusText,
                headers
            });
        }
    };


If You Want To, You Can Replace The Infinite Campus URL With https://raw.githubusercontent.com/InfiniteCampus41/InfiniteCampus/refs/heads/main So When Infinite Campus Goes Down, Your Link Will Stay Up. However, The Proxy Will Not Work I Think.


Step 4:

Click The Blue Deploy Button In The Upper Right Corner And Keep This Tab Open

Step 5:

Go To Github And Create A New Repo.

Step 6:

Name The Repo Something And Create 2 Files In The Repo. One Should Be Called index.html, And The Other Should Be Called sw.js

Step 7:

In The index.html File, Paste In The Following Code: 
                    
    <!DOCTYPE html>
    <html>
        <head>
        <script>
                if ("serviceWorker" in navigator) {
                    navigator.serviceWorker.register("/sw.js");
                }
            </script> 
        </head>
        <body>
            <script>
                (async function () {
                    if (sessionStorage.getItem("swReloaded")) return;
                    await navigator.serviceWorker.ready;
                    const status = document.createElement("div");
                    document.body.appendChild(status);
                    let seconds = 5;
                    const interval = setInterval(() => {
                        status.textContent = `Service Worker Ready. Launching In ${seconds}...`;
                        if (seconds-- <= 0) {
                            clearInterval(interval);
                            sessionStorage.setItem("swReloaded", "true");
                            location.reload();
                        }
                    }, 1000);
                })();
            </script>
        </body>
    </html>


In The sw.js File, Paste In The Following Code: 
                    
    const WORKER_URL = "YOUR WORKER URL HERE";
    self.addEventListener("fetch", event => {
        const url = new URL(event.request.url);
        if (
            url.pathname.startsWith("/.well-known") ||
            url.pathname === "/sw.js"
        ) {
            return;
        }
        if (
            url.protocol === "https:" ||
            url.protocol === "http:"
        ) {
            const currentOrigin = self.location.origin;
            if (url.origin !== currentOrigin) {
                return;
            }
        }
        event.respondWith(
            fetch(`${WORKER_URL}${url.pathname}${url.search}`, {
                method: event.request.method,
                headers: event.request.headers
            }).catch(() => fetch(event.request))
        );
    });


Step 8:

Go To The Settings Of The Repo, Then Go To Pages, Then Under Source, Select The Branch That You Pushed The Code To And Click Save

Step 9:

Wait For Github To Deploy The Page, Then Go To The URL That Github Gave You.
If It Does Not Load After The Countdown, Try Pressing Ctrl + Shift + R To Clear The Cache
